# Profiling data

This folder holds PGO (Profile-Guided Optimization) data for the CoreCLR Release build.

## `startup.mibc`

A `.mibc` (Managed IL Block) file generated by `maui profile startup` with PGO enabled.
When present, `crossgen2` uses it to optimize the R2R precompilation for startup-hot methods.

### How to generate / regenerate

```bash
# 1. Install the maui CLI tool (one-time)
dotnet tool install -g Microsoft.Maui.Cli --version "0.1.0-preview.12.26368.2"

# 2. Run the profiling session (builds + deploys + profiles in one step)
maui profile startup \
  --framework net11.0-android \
  --configuration Release \
  -p:MauiProfilingHelperEnableRuntimePgo=true \
  --format mibc \
  --stopping-event-provider-name Microsoft.Maui.ProfilingHelper \
  --stopping-event-event-name StartupComplete \
  --output Profiling/startup.mibc

# 3. Commit startup.mibc — every subsequent Release build will use it automatically
git add Profiling/startup.mibc
git commit -m "perf: update CoreCLR startup PGO profile"
```

### How it's used

The `.csproj` passes `--mibc` to `crossgen2` automatically when the file exists:

```xml
<PublishReadyToRunAdditionalArgs Condition="Exists('Profiling\startup.mibc')">
  --mibc:Profiling\startup.mibc
</PublishReadyToRunAdditionalArgs>
```

To rebuild without PGO (e.g. to compare):
```bash
dotnet build -p:UseMono=false -p:PublishReadyToRunAdditionalArgs="" -f net11.0-android
```

### Regenerate when

- The app's startup path changes significantly (new pages, new services registered)
- After a major MAUI / .NET version upgrade
- If startup performance regresses unexpectedly
