# Profiling data

This folder holds PGO (Profile-Guided Optimization) data for the CoreCLR Release build.

## `android-startup.mibc`

A `.mibc` (Managed IL Block) file generated by `maui profile startup` with PGO enabled.
When present, `crossgen2` uses it to AOT exactly the hot startup methods instead of the full app,
giving faster cold startup while keeping app size reasonable.

### How to generate / regenerate

```bash
# 1. Install the maui CLI tool (one-time)
dotnet tool install -g Microsoft.Maui.Cli --prerelease

# 2. Run the profiling session — builds, deploys and profiles in one step
cd samples/HorusStudio.Maui.MaterialDesignControls.Sample
maui profile startup --format mibc

# The tool outputs android-startup.mibc in the current directory.
# Move it to the Profiling/ folder:
mv android-startup.mibc Profiling/android-startup.mibc

# 3. Commit — every subsequent Release build picks it up automatically
git add Profiling/android-startup.mibc
git commit -m "perf: update CoreCLR startup PGO profile"
```

### How it's used

The `.csproj` feeds it to `crossgen2` via the `_ReadyToRunPgoFiles` item (the correct MSBuild hook):

```xml
<ItemGroup Condition="Exists('Profiling\android-startup.mibc')">
  <_ReadyToRunPgoFiles Include="Profiling\android-startup.mibc" />
</ItemGroup>
```

To rebuild without PGO (e.g. to compare baselines), temporarily rename/remove the `.mibc` file
or comment out the ItemGroup above.

### Regenerate when

- The app's startup path changes significantly (new pages, new services registered)
- After a major MAUI / .NET version upgrade
- If startup performance regresses unexpectedly
